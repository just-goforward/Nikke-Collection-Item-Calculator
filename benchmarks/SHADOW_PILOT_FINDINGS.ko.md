# Shadow-price 후보 모델 pilot 평가 결과

영문 원본: [`SHADOW_PILOT_FINDINGS.md`](./SHADOW_PILOT_FINDINGS.md)  
분석 일자: 2026-05-27

## 최종 결론

현재 정의의 B(`single-update shadow-price`)와 C(`bounded fixed-point shadow-price`)는
활성 `supply` 정책 A의 **제품용 대체 후보로 기각**되었습니다.

- 제품의 기본 `solve()` 동작은 변경하지 않았습니다.
- `solverVersion`도 변경하지 않았습니다.
- 연구용 API와 결정적 pilot 코드는 향후 재설계 비교 근거로 유지할 수 있습니다.

## 평가 절차 종료 범위

| 절차 | 상태 | 의미 |
| --- | --- | --- |
| A exact 기준선 검증 | 완료, 통과 | 후보 비교 평가의 전제 충족 |
| B/C 연구 전용 구현 | 완료 | 제품 경로에는 연결하지 않음 |
| root-policy pilot | 완료 | 초기 후보의 local `F` 악화 발견 |
| safeguard 적용 후 exact interactive pilot | 완료 | 채택 필수 조건 위반 확인 |
| B/C 채택 판정 | 완료, 기각 | 현재 후보는 제품 대체 불가 |
| D1 가중 위험군 분석 | 미실행 | 이미 기각된 후보를 구제할 수 없어 불필요 |
| 전체 그리드 tail-risk 유의성 평가 | 미실행 | 필수 exact 조건 통과 후보에만 필요한 후속 단계 |

즉, **현재 B/C 후보를 채택할지 결정하는 데 필요한 절차는 끝났습니다.** 새로운 후보를
설계한다면 그 후보에 대해서는 별도 평가가 다시 필요합니다.

## 적용한 필수 채택 기준

다음 조건은 pilot 단계에서도 반드시 만족해야 했습니다.

1. exact interactive-replan 성공 확률은 A보다 낮아지면 안 됩니다.
2. 보호 시나리오에서 제품 관련 기대 소비 목적 함수인 interactive `F`는 악화되면
   안 됩니다. `F`는 낮을수록 좋습니다.
3. 기존 `max - 0.01` probability gate 위반은 0건이어야 합니다.

B/C는 저비용 결정적 시나리오에서 1번 또는 2번 조건을 이미 위반했습니다. 따라서 더
비싼 평가를 추가해도 현재 정의의 B/C가 제품 채택 후보가 되지는 않습니다.

## 평가한 모델

| 모델 | 설명 |
| --- | --- |
| A | 현재 제품 정책 `phase1_availability_pnorm` |
| B | A 결과에서 gradient price를 한 번 갱신한 후 linear shadow-price solve를 한 번 수행 |
| C | damping을 적용한 fixed-point price 갱신을 반복하며, 반복 상한, cycle 감지, timeout, A fallback 포함 |

초기 root-policy pilot에서는 원시 B/C 후보가 root `F`를 악화시키는 문제가
확인되었습니다. 이후 각 재계산 경계에서 후보의 committed-policy `F`가 A보다 나쁘면
A로 돌아가는 local monotonic safeguard를 추가했습니다. 아래 exact 결과는 이
safeguard가 적용된 후보 기준입니다.

## 후속 조치

- B 또는 C를 제품 `solve()`에 연결하지 않습니다.
- `solverVersion`을 변경하지 않습니다.
- 현재 B/C에 대한 D1 가중 strata 평가와 전체 trajectory tail-significance 평가는
  수행하지 않습니다.
- 향후 새 후보를 설계할 경우 local root safeguard만으로는 충분하지 않다는 점을
  전제로, interactive 결과가 악화되지 않는지를 다시 검증해야 합니다.
